# Forge Table documentation

| Page | Read it when |
|---|---|
| [Install](forge-table/install.md) | You want to run Forge Table: release zip, Docker, or straight from a source checkout. |
| [Configuration reference](forge-table/configuration.md) | You need a setting. Every flag, `FT_*` variable, config-file key and default is there. |
| [Hosting for a group](forge-table/hosting.md) | Several people will play on one server: sign-in with Forge Table's own accounts, OIDC or a login proxy. |
| [Card art](forge-table/card-art.md) | You want to know where the pictures come from, where they're cached, or how to turn them off. |
| [Neural AI plugin](forge-table/ai-plugin.md) | You have a neural AI opponent to plug in, or wonder what the "Neural" option is. |
| [Building and testing](forge-table/building.md) | You're changing the code. |
| [Architecture](forge-table/architecture.md) | You want to know how the browser client, the router and the per-game JVMs fit together. |
| [FAQ and troubleshooting](forge-table/faq.md) | Something doesn't work, or you have a question the other pages don't answer. |
| [Maintainer runbook](forge-table/RUNBOOK.md) | You maintain the project: the long-form notes on the protocol, replay fixtures, sizing measurements and the reference systemd deployment. |

The other pages in this folder (`Home.md`, `User-Guide.md`, `AI.md`, the card-scripting pages and so on) are the
upstream Forge project's documentation for its desktop and mobile apps, kept because Forge's engine and card scripts
live in this repository. They describe Forge, not Forge Table. [Forge-engine-README.md](Forge-engine-README.md) is
Forge's original README.
