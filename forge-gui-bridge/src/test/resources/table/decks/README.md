# Vendored Pauper decks

The 12 Pauper decks the mtg-ai project trains and evaluates on, copied from
`decks/pauper/2026-09-28/` of the mtg-ai repository at commit
`1964e2ba1e25d2d9a5911773bdc3cdb133936b5e`. `DeckFixturesTest` fails if any card in them is
unknown to the card database. Recommended pairings: madness vs faeries, affinity vs
terror, ephemerate vs wildfire, ponza vs elves.
